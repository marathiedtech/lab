# DzynCode v4 — Student project workspace

- Create files; rename and delete files.
- All project files stay together in one project workspace (no in-app folder tree).
- Auto-save in browser storage.
- Export all files as a ZIP to share with the teacher.
- On supported browsers, choose a device folder and save project files directly into it using the File System Access API.
- HTML/CSS/JS live preview and basic CodeMirror hints.

## Device folder support
Direct folder access depends on browser and device support. On Android/mobile browsers where folder access is unavailable, use **Export ZIP**. The ZIP contains the student's complete project and can be shared via WhatsApp, email or LMS.

## Publish
Replace repository root files `index.html`, `style.css`, `app.js`, `README.md` and commit changes.
