# DzynCode — Pocket Coding Lab (v3.1 hotfix)

Mobile-friendly HTML/CSS/JavaScript coding playground with folders, files, preview, local autosave, ZIP download and basic code hints.

## Publish/update
Replace the repository root files `index.html`, `style.css`, `app.js`, and `README.md` with these files. Commit changes, then refresh the GitHub Pages site after deployment completes.

## Important
- Suggestions can be opened with Ctrl+Space on a keyboard. On-screen mobile keyboard behavior depends on the browser and may not expose this shortcut.
- Projects are saved only in the same browser/device using localStorage.
- Preview supports HTML/CSS/JavaScript only.
- CodeMirror and JSZip load from CDNs, so internet access is required.
